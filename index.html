路线：三天扫完

大件的真正成本不是货价，是跑腿。把同一片区的卖家串成一天，比一件件跑省下的钱多得多。你们有 van，按下面这个顺序走。

Day 1 · 北岸

Albany → Pinehill → Schnapper Rock → Browns Bay

  1. Albany 清仓（洗衣机 $400 / 烘干机 $400 / 餐桌6椅 $600 / 升降桌 $150 / Queen 床 $200）—— 整单开 $1500
  2. Albany 全新家具合集（95新，床架床垫斗柜升降桌电脑椅）—— 同区，顺路第二家
  3. Pinehill：海尔冰箱 $120、Bosch 洗衣机 $499（可拿来和 Albany 那台比价压价）
  4. Schnapper Rock：法式实木餐桌 + 6 椅 $310（可小刀）
  5. Browns Bay：实木 Queen 床架 $50
  6. Takapuna：三菱冰箱 420L $240 · Windsor Park：LG 冰箱 $220（这家可以送货，能省则省）
Day 2 · 中区 + 西区

Mt Eden → Newmarket → Mt Albert → New Windsor → Westgate

  1. Mt Eden：整套真皮沙发 $650（3人位 + 2 单人 + 单座）、免费微波炉
  2. Newmarket：Queen 床架 + 床垫 $120
  3. Mt Albert：皮质餐椅 $60（先问有几把）
  4. New Windsor：免费床架 + 柜子（床垫别要）
  5. 中区：实木餐桌 117×77（四腿可拆，轿车就能装）
  6. Westgate：双人沙发 $60 —— 全表沙发性价比第一
Day 3 · 东区 / City（按需）

Howick → Flatbush → Glendowie → City

  1. 东区：9 成新 8kg 洗衣机（还在保修期，全表成色最好）—— 这一单值得专程
  2. Flatbush：儿童书架 $25 / 茶几 $40 / 大理石边几 $60
  3. Glendowie：Harvey Norman 沙发（原价 $2999，先问价）
  4. City：出家具帖（价格标在图上，City 范围可帮忙送）、五抽柜、桌上型升降台

第一条消息怎么发

小红书出闲置的节奏很快，第一条消息问得全不全，直接决定你要不要白跑一趟。三个模板，直接改了发。

通用版

你好！看到你出的〔物品名〕，我们月底搬到奥克兰，想收一个。先确认几件事：
1）现在还在吗？
2）能不能发两张最近拍的实拍图，包括有瑕疵的地方？
3）买了多久、有没有明显磨损或异味？
4）需不需要现场拆卸，我要不要带工具？
5）方便的话哪天可以自提？我们有 van，可以自己搬。
如果合适我这周就能来取。谢谢！

砍价版（对方写了瑕疵时）

谢谢！图我看了，整体挺好的。就是〔具体瑕疵，例如：横木需要更换 / 坐垫弹簧塌了 / 显示屏不能调温〕这块我回去还得处理一下，
加上我从〔你们的位置〕过去要跑一趟，〔出价〕的话我今天就定，明天来取，你看行吗？

打包版（同一卖家多件）

你好，我看你还有〔A〕〔B〕〔C〕，我们刚搬过来正好都需要。这几件我一起要，一趟车拉走，也帮你省事。
整单〔总价〕可以的话我今天就定下来。

砍价的四个真实抓手 · 和八个坑

🔪 有效的砍价理由

  • 用自提距离。「我从〔北岸／中区〕过去要跑一趟，油钱加时间不少」—— 最容易被接受，尤其对方写了「仅自提」。
  • 用需要自拆。床架、大衣柜通常要现场拆。「我得带工具来拆，拆装大半天」是合理的减价理由。
  • 用瑕疵。对方主动写了瑕疵，说明他心里已经打了折 —— 顺着这个点报价，成功率最高。
  • 用打包。同一卖家多件一起拿，砍价空间最大，卖家也最欢迎（他最怕零零散散卖不完）。
  • 不要硬砍。写明「不议价」「免屠龙刀」的，别碰这个雷。换个角度问「能不能约在市区交接」，省下的路费一样是钱。

🕳️ 八个坑

  • 九成新 ≠ 九成新。很多是战损版。一律要最近实拍，最好拍瑕疵特写。
  • 最忌讳「家具50，运费150」。下手前先算：物品价 + 货运费 vs 新品促销价。接近就直接放弃。
  • 免费帖基本抢不到。有人开货车天天守着。看到就发消息，别斟酌措辞。
  • 二手床垫是最高风险品。螨虫、污渍、塌陷都不可逆。除非近新且有防螨套，否则宁可买新的（NZ 促销 Queen 床垫 $300-500）。
  • 提货日期要钉死。打算一天搬完的话，每个卖家的时间都要提前对齐，错开会让货车费翻倍。
  • 「付定金预留」要谨慎。表里桃花心木餐桌那条写了「定金不退」，坚持当面看货当面付。
  • 「本人不在国内」= 代卖。只看图不够，要求视频看货。
  • 电器一定要通电试。洗衣机至少跑一个快洗看排水和脱水；冰箱摸冷冻室、听压缩机；电动沙发试三个马达。
